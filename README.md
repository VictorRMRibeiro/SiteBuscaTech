# Monitoria da Faculdade

Repositório público da monitoria para centralizar materiais, avisos e referências para estudantes.

## Objetivo
- Compartilhar conteúdo de apoio da disciplina
- Organizar cronograma, listas e materiais
- Facilitar contribuições dos estudantes por pull request

## Estrutura
- `/ementa` — ementa da disciplina
- `/cronograma` — cronograma de encontros e atividades
- `/listas` — listas de exercícios e resoluções
- `/materiais` — materiais de apoio (slides, anotações e referências)
- `/links` — links úteis
- `/contatos` — canais de contato da monitoria

## Acesso e colaboração
- Leitura: aberta para qualquer estudante
- Manutenção: equipe de monitores
- Contribuições: via fork + pull request

Veja [CONTRIBUTING.md](CONTRIBUTING.md) para detalhes de contribuição.
