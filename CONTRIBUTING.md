# Como contribuir

Obrigado por contribuir com a monitoria.

## Fluxo de contribuição
1. Faça um fork deste repositório
2. Crie uma branch para sua contribuição
3. Faça as alterações necessárias
4. Abra um pull request descrevendo claramente a mudança

## Regras básicas
- Não envie alterações direto na `main`
- Mantenha os arquivos organizados nas pastas corretas
- Use títulos e descrições claras nas contribuições
- Respeite o escopo acadêmico da monitoria

## Sugestões de contribuição
- Correção de erros de digitação
- Inclusão de materiais complementares
- Melhoria de descrições em listas e cronogramas
- Atualização de links úteis
